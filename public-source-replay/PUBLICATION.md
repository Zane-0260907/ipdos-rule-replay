# Public derivative and offline reproduction

This public copy comes from the reviewed corrected v1 archive. Its original SHA-256 is recorded in PUBLIC_DERIVATION.json. Nine production core modules, all executable wrappers and oracles, the frozen 30-transition source contract, downloaded metadata, and all original and validation result records/databases are unchanged. Three metadata JSON files omit private Library identifiers and replace historical machine-specific paths with placeholders. The original checksum list is archived under provenance; the current SHA256SUMS.json applies to this public derivative.

The versioned replay ZIP contains all 240 researcher-generated SQLite databases (120 original cases and 120 separate portability-verification cases). They are entirely synthetic counterfactual approval/signoff/receipt fixtures and contain no real account or purchasing database. A Git checkout omits those binary case files: download and extract the replay ZIP for the archived audits, or run node run-replay.cjs to generate fresh synthetic cases before node audit-replay.cjs. No original desktop folder, account, token, package install or network is needed for offline replay.

The package's own portability record identifies its actual Windows validation platform. External platform checks are not inferred from that record. Deterministic case counts and audit assertions are not independent participant observations, real approval events or production failure probabilities.
